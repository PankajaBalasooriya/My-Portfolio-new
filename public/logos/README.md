# Institution logos

Drop logo files here, then reference them by filename from the YAML in
`src/data/` — e.g. `logo: university-of-moratuwa.svg`.

- **SVG preferred**; PNG or WebP at roughly 200px wide is fine otherwise.
- Files here are served verbatim, so keep them small.
- Every logo renders on a light chip, so a single normal-colour file works in
  both themes. Supply `logoDark` only if one genuinely needs it.
- Use official artwork from the institution's brand or press page. These are
  trademarks; identifying a real affiliation is normally fine, redrawing or
  restyling them is not.
